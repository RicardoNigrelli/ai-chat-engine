# Sobre chat-general

chat-general es un motor de chat con IA reusable en múltiples aplicaciones.
Incluye tools configurables (calculadora, fecha/hora, lectura de páginas web,
búsqueda web y búsqueda en base de conocimiento) y un módulo de RAG genérico
para cargar documentos propios.

Este archivo es un documento de ejemplo para probar el flujo de RAG: correlo
con `npm run ingest -- ./knowledge` y después preguntale al chat "¿qué es
chat-general?" para ver cómo la tool knowledgeBaseSearch lo encuentra.
